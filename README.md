## 📌 Sobre o Projeto

Este repositório contém todo o código-fonte, documentação e materiais desenvolvidos para o meu **Trabalho de Conclusão de Curso (TCC)** no curso de Análise e Desenvolvimento de Sistemas




## 🛠️ Tecnologias e Ferramentas

O projeto faz uso das seguintes tecnologias:

- **Linguagens:** Python / JavaScript / C++ 
- **Frameworks & Libs:** FastAPI / Flask / React / Node.js 
- **Banco de Dados:** MySQL / PostgreSQL / MongoDB 
- **Outras Ferramentas:** Docker, Git, VS Code
